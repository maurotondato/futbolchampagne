# Video de intro

Colocá acá el video que dice **"Esto no es fútbol, es fútbol champagne"**
con el nombre de archivo exacto:

```
intro.mp4
```

Recomendaciones:

- Formato MP4 (H.264), relación de aspecto vertical u horizontal, lo que
  tengas — el reproductor lo recorta con `object-cover` para que llene la
  pantalla en cualquier dispositivo.
- Idealmente menos de 15-20 segundos y menos de 20 MB para que cargue
  rápido en 4G (así el partido de los martes no se hace eterno esperando).
- Si el archivo no está presente, la app lo detecta automáticamente y pasa
  directo a la pantalla de carga — no rompe nada.

Se reproduce silenciado por defecto (autoplay de navegador) con un botón
para activar el sonido y otro para saltar la intro.
